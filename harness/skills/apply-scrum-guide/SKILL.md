# Scrum Guide を適用する

Scrum Guide を唯一の規範的な基準として扱い、チームが経験主義と自己管理によって有効性を高められるよう支援する。答えを押し付けず、透明性を上げ、検査可能な事実から適応を促す。成果物や実装も求められる場合は、それを扱う能力と併用し、Scrum の判断を置き換えない。

## 必ず守る原則

- Scrum の定義、役割、イベント、作成物、コミットメントは、[根拠資料](references/sources.md)の Scrum Guide だけを出典とする。Scrum Guide に明記されていない実務慣行を、Scrum の必須要素であるかのように語らない。
- Scrum Master はチームの有効性と Scrum の確立に責任を持つ（原文の引用は [scrum-master-role.md](references/scrum-master-role.md)）。
- チームを管理対象ではなく、自己管理する専門家として扱う。まず問い、観察し、選択肢を示し、チームが決められる余地を残す。
- 人ではなく、システム、相互作用、制約、方針、フィードバックループを診断する。個人の速度、稼働率、発言数を評価指標にしない。
- 事実、推論、提案を区別する。データがない場合は断定せず、必要最小限の観測を設計する。
- Scrum の不完全な実施を、便宜的に「Scrum」と正当化しない。意図的な変更なら、何を変えたか、なぜか、失う検査と適応の機会を明示する。

## 手順

1. **状況を揃える。** 依頼から判断できない重要事項だけを、まとめて確認する: 目指す成果と期限、プロダクトと利用者と Product Goal、チーム構成と各アカウンタビリティと意思決定権、Sprint の長さと現在地、Sprint Goal と Definition of Done と主要な阻害要因、利用できる事実。可逆的な仮説として進められる場合は、仮定を明示して進める。緊急の障害や、安全・法令・重大インシデントでは、イベント設計より封じ込めと適切なエスカレーションを優先する。
2. **成果と観測事実を定義する。** 「会議を良くする」ではなく、価値・行動・時間で表す。利用可能なデータを確認し、観測事実、関係者の解釈、未検証の仮説を分ける。
3. **三つの層で診断する。** プロダクト（価値、利用者、Product Goal、フィードバック）、チーム（Sprint Goal、Definition of Done、自己管理、スキル、フロー、品質、相互作用）、組織（権限、依存関係、承認、資金、方針、インセンティブ、ステークホルダーとの距離）。Scrum の透明性・検査・適応のどこが弱いか、Scrum Values のどれが損なわれているかを確認する。原因を単一の人物に帰属させない。
4. **最小の有効な介入を選ぶ。** まず目的、データ、制約を透明にする。チームが自力で解けるなら、問いと場を提供する。障害の所有者がチーム外なら、影響と必要な決定を具体化して、支援とエスカレーションを行う。大規模な制度変更より、短い改善実験を優先する。
5. **実行可能な提案にする。** 次の順で答える: 結論（最も重要な判断または推奨）、根拠（事実と、明示した推論）、次の一歩（担当、行動、期限）、成功判定（ベースライン、指標、観測期間）、リスク（副作用と緩和策）。複数案が実用的な場合だけ2〜4案を比較し、推奨を一つ示す。
6. **経験主義で閉じる。** 提案を恒久ルールにせず、仮説、小さな変更、先行指標と結果指標、検査日、継続・修正・中止の判断基準を決める。

## 成果物を作るとき

- 単発のアジェンダ、チェックリスト、短いテンプレートは、会話の中か軽量な文書で足りる。
- 利用者が提示・共有する資料（レトロスペクティブの資料、Sprint Review の資料、チーム憲章）は、求められた形式を扱える能力を併用し、Scrum の判断と、その形式に固有の検証の両方を保つ。
- 作成物やイベントの記録をリポジトリの中のファイルとして置き、保つ依頼は、それを扱う能力に委ねる。このスキルはファイルを書かない。
- 「Scrum Guide が規定する事項」と「このチームが自分で決めること」を、常に区別する。

## 完了の確認

- Scrum Guide の規定以外の内容を、規定として紛れ込ませていない。
- 誰が決めるか、誰が実行するかを取り違えていない。
- 提案が、会議の開催ではなく、検査・適応または価値の提供に結び付いている。
- 推奨がチームの自己管理を弱めていない。
- 次の検査時点と成功判定がある。
- 重大な主張に、[sources.md](references/sources.md)の出典を付けられる。
