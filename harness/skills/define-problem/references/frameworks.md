# Frameworks behind the four elements

Read when naming or citing the framework an element comes from. The definition of a problem as a gap converges independently across quality management, structured problem solving, business analysis, and Lean practice. Cite only these sources; do not attach an uncited framework to an element.

| Element | Source | What it contributes |
|---|---|---|
| Current state | International Institute of Business Analysis (IIBA), *A Guide to the Business Analysis Body of Knowledge (BABOK Guide)*, v3, 2015 | Current-state analysis |
| Current state | John Shook, *Managing to Learn: Using the A3 Management Process*, Lean Enterprise Institute, 2008 | The "Current Condition" of Toyota's A3 process |
| Ideal state | Kaoru Ishikawa, *Guide to Quality Control*, Asian Productivity Organization, 1976 | A problem as the gap between what should be and what is |
| Ideal state | BABOK Guide v3; Shook 2008 | "Future state"; the A3 "Target Condition" |
| The gap | Charles H. Kepner & Benjamin B. Tregoe, *The New Rational Manager*, Princeton Research Press, 1981 | A problem as a deviation from an expected performance standard |
| The gap | Shook 2008 | The A3 problem statement as a measured gap between current and target conditions |
| Significance | Kepner & Tregoe 1981 | A deviation is a problem worth analyzing only when it is significant enough to warrant corrective action |
