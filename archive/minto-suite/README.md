# Archived: Minto document suite

`minto-builder`, `minto-reviewer`, and `minto-rewriter` (with their Japanese
mirrors and translations) were retired from the managed `.claude/` tree when
the `minto-pyramid` plugin was vendored. They are kept here for reference only:
`install.sh` does not sync this directory and nothing here is loaded by Claude
Code. To restore one, move it back under `.claude/skills/` and re-add it to
`authored_skills` in `tests/run-config-pyramid.sh`.

The directory layout mirrors the original repository paths.
