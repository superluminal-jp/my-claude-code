# Long-form document template

Use a recursive pyramid rather than a fixed section list.

- Open with the document's governing answer or executive conclusion when the genre permits.
- Each section lead states the section's conclusion, not only its topic.
- Each subsection directly supports its parent section.
- Keep peer sections comparable in abstraction and ordering logic.
- Place evidence, methods, appendices, and implementation detail at the lowest useful level.
- For problem framing, use SCQ only when needed to establish the governing question.
- For technical or academic genres whose conventions require another order, follow the genre while preserving the logical dependency structure.
