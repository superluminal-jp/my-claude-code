# Substantive answer template

Use only when it improves clarity; do not force headings for short answers.

1. **Governing answer** — answer the user's controlling question directly.
2. **Support** — 2–4 first-level claims that directly justify the answer.
3. **Evidence/detail** — facts, examples, calculations, implementation details, or caveats nested under the claim they support.
4. **Action/decision** — include only when the user needs a next step.

Avoid an end-of-answer summary that merely repeats the opening answer.
