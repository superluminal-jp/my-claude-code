# Minto source and purpose

## Primary source

Barbara Minto, *The Minto Pyramid Principle: Logic in Writing, Thinking and Problem Solving*, Minto Books International, 1996.

The work presents a method for organizing thinking and communication so that a single governing idea is supported by hierarchically grouped ideas, with explicit vertical and horizontal logical relationships.

## 日本語

Barbara Minto『The Minto Pyramid Principle: Logic in Writing, Thinking and Problem Solving』Minto Books International, 1996.

本プラグインでは、同書を「一つの中心的な問いに対して結論を先に定め、その結論を同一階層の論理的な主張群で支持し、証拠・詳細を下位に配置するための思考・コミュニケーション方法論」として運用的に抽象化している。
