# 0007. scripts/ をすべて削除する

## コンテキストと問題

ADR-0005でClaude Codeのフックを、ADR-0006でpermissions設定を、それぞれ
代替なしで削除した。その結果、`scripts/guardrails/*.sh` は自動実行されない
参照実装となり、専用テストだけが残っていた。また、同じ `scripts/` 配下には
独立したMCPカタログ整合性チェッカーもあり、リポジトリ内のスクリプト群を
維持・配布・検証する責任が残り続けていた。

保守者は、ガードレールの参照実装だけを残す案に加え、用途の異なるMCP整合性
チェッカーを残す案についても個別に検討し、いずれも削除することを明示的に
選択した。AcceptedであるADR-0005とADR-0006は当時の判断を記録する履歴なので、
内容を更新せず、新しい決定として記録する必要がある。

## 決定要因

- 実行されない参照実装と、その実装だけを対象にしたテストの保守を終える。
- リポジトリに残るスクリプトの用途、配布先、実行主体を追跡する負担をなくす。
- ADR-0005、ADR-0006から続く「Claude Code側の自動強制を持たない」という状態を
  ファイル構成にも一貫して反映する。
- Accepted ADRを上書きせず、決定の変遷を追記型で残す。

## 検討した選択肢

- ガードレールスクリプトと専用テストを参照実装として維持する。
- ガードレールスクリプトだけを削除し、MCP整合性チェッカーは維持する。
- **専用テストを含めて `scripts/` をすべて削除する。**（採用）

## 決定

`scripts/guardrails/`、その4つの専用テスト、および独立した
`scripts/check-mcp-consistency.sh` を削除し、リポジトリから `scripts/`
ディレクトリをなくす。

過去のインストールで残った `~/.claude/scripts/guardrails/` は、
`install.sh` が無条件に削除する。MCP定義の完全性と権限・安全性に関する文書は
引き続き方針として維持するが、このリポジトリ内のスクリプトによる自動検証は
行わない。

### 影響

- Positive: 実行主体のない参照実装、専用テスト、配布処理を保守する必要がなくなる。
- Positive: リポジトリの実態とREADME・ルール文書が一致し、`scripts/` が現役の
  仕組みだと誤認されなくなる。
- Negative: ガードレールのパターン照合ロジックを参照または直接実行できなくなる。
- Negative: MCPカタログの定義漏れやドリフトを自動検出する専用チェックがなくなり、
  `.mcp.json`、`install.sh`、設定、文書の整合性は手動レビューに依存する。
- Negative: 削除した振る舞いを復活させる場合、実装だけでなくテストと配布方法も
  改めて設計する必要がある。

## 確認方法

`scripts/` と4つの専用テストが存在しないこと、現役の文書が削除済みスクリプトを
利用可能な仕組みとして説明していないこと、`install.sh` が過去のインストール先を
削除すること、および残存する `tests/run-*.sh` が通ることを確認する。具体的な
検証手順は `specs/027-remove-scripts/quickstart.md` に記録する。
