# コントラクト: `list_notes.js`（フォルダ一覧 / 単一ノート取得）

対応要求: FR-006, FR-007。呼び出し形: `osascript -l JavaScript list_notes.js [<folder-name> | --id <id> | --folders]`

## 入力

| 形式 | 説明 |
|---|---|
| `<folder-name>` | そのフォルダに含まれるノートを一覧する。 |
| `--id <id>` | 単一ノートを識別子で取得する。 |
| `--folders` | アカウント内の全フォルダを一覧する。 |

共通オプション:

| オプション | 説明 |
|---|---|
| `--with-body` | 一覧取得時、各ノートの `body`（HTML）を含める。既定では省略する（FR-006）。 |
| `--plaintext` | `body` を HTML タグ除去済みのプレーンテキストとして返す。読み取り専用用途。この出力を書き戻す入力として使ってはならない（不可逆変換）。 |
| `--field <name>` | 単一ノート取得（`--id`）時、その1フィールドのみを生の文字列として返す（JSON配列でなく）。ハッシュゲート計算などスクリプト連携向け。 |

## 出力（JSON, stdout）

一覧・単一取得ともに JSON 配列。各要素:

```json
{
  "id": "<note-id>",
  "name": "<derived-title>",
  "body": "<HTML or omitted>",
  "folder": { "id": "<folder-id>", "name": "<folder-name>" },
  "creationDate": "<ISO8601>",
  "modificationDate": "<ISO8601>"
}
```

`--field <name>` 指定時は上記オブジェクトの1フィールドの生文字列を返す。

## 挙動・制約

- クエリ言語は存在しない。フォルダ内容の絞り込みは全件取得後に呼び出し側で行う（FR-006 の「既定では本文省略」がこの絞り込みコストを抑える主手段）。
- `--id` が存在しない識別子の場合は空配列またはエラーで失敗する（曖昧に空ノートを返さない）。
