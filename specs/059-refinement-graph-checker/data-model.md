# Data Model: 宣言ファイルの要素と検証の規則

宣言ファイルは2種類あり、どちらもノードの配列である。各欄がないとき・誤っているときにどの規則の違反になるかを、欄ごとに示す。規則の意味は [spec.md](spec.md) の FR-003 にある。

## 1. 要求のノード(`requirements` の要素)

| 欄 | 型 | 必須 | ないとき・誤っているとき |
|---|---|---|---|
| `id` | 空でない文字列 | はい | ない・空: S-01。文字列でない: S-00。重複: S-01 |
| `statement` | 空でない文字列 | はい | ない・空・文字列でない: S-00 |
| `decomposition` | `AND`・`OR`・`LEAF` | はい | ない・ほかの値: S-04 |
| `children` | 文字列の配列 | いいえ(既定は空) | 配列でない・文字列でない要素: S-00。未定義の ID・同じ ID の重複: S-02 |
| `acceptance` | 受け入れ条件の配列 | はい(1件以上) | ない・空: S-06。配列でない: S-00 |
| `assumptions` | 文字列の配列 | いいえ | 型の誤り: S-00 |
| `counterexamples` | 文字列の配列 | いいえ | 型の誤り: S-00 |
| `selection` | 子の ID から空でない条件の文字列への対応 | OR だけ | オブジェクトでない・値が文字列でない: S-00。OR で子の条件がない・空・子でない ID がある、OR でないのに持つ: S-05 |

ほかの欄は S-00 の違反である。

## 2. 受け入れ条件(`acceptance` の要素)

| 欄 | 型 | 必須 | ないとき・誤っているとき |
|---|---|---|---|
| `id` | 空でない文字列 | はい | ない・空・文字列でない・グラフ全体での重複: S-07 |
| `description` | 空でない文字列 | はい | ない・空・文字列でない: S-00 |
| `level` | `L1`・`L2`・`L3` | はい | ない・ほかの値: S-07 |

要素がオブジェクトでない、またはほかの欄を持つときは S-00 の違反である。

## 3. スキルのノード(`skills` の要素)

| 欄 | 型 | 必須 | ないとき・誤っているとき |
|---|---|---|---|
| `id` | 空でない文字列 | はい | 要求のノードと同じ(S-01、S-00) |
| `children` | 文字列の配列 | いいえ(既定は空) | 要求のノードと同じ(S-00、S-02) |
| `permission` | `read_only`・`workspace_write`・`external_effect` | はい | ない・ほかの値: S-09 |
| `role` | `orchestrator`・`worker`・`auditor`・`checker` | はい | ない・ほかの値: S-09 |

ほかの欄は S-00 の違反である。`role` が `auditor` か `checker` のノードは、自分の `permission` と、子をたどって届くすべてのノードの `permission` が `read_only` でなければ S-09 の違反である。

## 4. 互換モードのスキル

`--skills-dir DIR` の直下で `SKILL.md` を持つサブディレクトリが1つのスキルであり、ディレクトリの名前が ID である。子は `SKILL.md` の「`## Child skills`」節の宣言である(research.md の R6)。権限と役割の欄はないため、S-09 は判定しない。

| 状態 | 違反 |
|---|---|
| 宣言した子のディレクトリに `SKILL.md` がない | S-02 |
| 同じ子を二度宣言する | S-02 |
| 自分自身を宣言する、または宣言をたどって戻る | S-03 |
| 宣言した子が自分の子を宣言する | S-10(親のノードに報告する) |

## 5. 関係

- 要求のノードとスキルのノードは、それぞれの `children` で親から子へのエッジを持つ。一つの子が複数の親を持ってよい(S-08)。
- 受け入れ条件は、それを持つ1つの要求のノードに属する。ID はグラフ全体で一意であり、ほかのノードと共有しない。
- 状態の遷移はない。検査器は宣言を読むだけで、ノードの状態を持たない。
