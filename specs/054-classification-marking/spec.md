# Feature Specification: 各スライド右上の機密性・公開範囲の表示

**Feature Branch**: `claude/digital-agency-slide-skill-vqe5ky`

**Created**: 2026-10-28

**Status**: Draft

**Input**: User description: "機密性1/2/3と公開範囲(xxxのみ)を示すボックスを各スライドの右上に配置するようにする"

**Authority**: 本仕様が正である。機密性の区分(1〜3)は政府機関等のサイバーセキュリティ対策のための統一基準に由来するが、各区分の定義と表示の細則は組織ごとの規程が定める。スキルは区分を決めず、作成者または組織の規程から受け取る。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - どのスライドにも、機密性と公開範囲が右上に示される (Priority: P1)

資料の受け手は、どのスライド(表紙・付録を含む)を見ても、印刷したどのページを見ても、右上の枠で、その情報の機密性(1/2/3)と公開範囲(例:「△△課のみ」)を知る。

**Why this priority**: 利用者の直接の依頼。表示の欠けたページや食い違ったページは、取扱いを誤らせる。

**Independent Test**: テンプレートの全スライドに同じ表示があり、右上にあり、`lint` が欠落・食い違い・不正な区分・位置の誤りを報告する。

**Acceptance Scenarios**:

1. **Given** テンプレート、**When** どのスライドを見ても、**Then** 右上の安全域の線上に、機密性(太字)と公開範囲を区切って並べた枠がある。本文や現在地の表示と重ならない。
2. **Given** あるスライドだけ表示が無いデッキ、**When** `lint` を実行する、**Then** そのスライドについてエラー `marking-missing` が出る。どのスライドにも表示が無いデッキでは、文書全体についてエラー `marking-missing` が出る。
3. **Given** 機密性または公開範囲が最初のスライドと異なるスライド、`data-level` が 1〜3 でないスライド、表示の区分の数字が `data-level` と異なるスライド、公開範囲が空のスライド、または表示が右上にないスライド、**When** `lint` を実行する、**Then** そのスライドについてエラー `marking` が出る。
4. **Given** テンプレート、**When** 公式資材を取得して `lint` を実行する、**Then** 所見は0件で、本編は7枚のまま。

---

### User Story 2 - 機密性を推測しない (Priority: P1)

資料の作成を頼まれたとき、スキルは機密性と公開範囲を作成者に確かめてから作る。推測で区分を書かない。

**Independent Test**: スキルの手順と注意事項が、区分と公開範囲を作成者または組織の規程から受け取り、推測しないことを定める。

**Acceptance Scenarios**:

1. **Given** スキルの手順、**When** 読む、**Then** 着手前に確かめる事項に機密性と公開範囲が含まれ、注意事項が区分を推測しないことを定める。

### Edge Cases

- 機密性1の資料も表示する(依頼は1〜3のすべて)。
- 区分の定義を本スキルに書き写さない。組織ごとに異なり、写しは古くなる。
- 表示は色だけで区分を示さない(文字で示す)。

## Requirements *(mandatory)*

- **FR-001**: テンプレートは全スライドの右上に `sld-marking` を持ち、余白を調整して本文・現在地の表示と重ならない。
- **FR-002**: `lint` は User Story 1 の受け入れシナリオ2・3のとおりに報告する。
- **FR-003**: `SKILL.md`、設計・マークアップ・検査の参照文書、README(英・日)は変更後の挙動と一致する。

## Success Criteria *(mandatory)*

- **SC-001**: 表示の fixture で、期待した `marking` と `marking-missing` だけが報告される。
- **SC-002**: テンプレートは所見0件、本編7枚(E2E)。

## Assumptions

- 表示の文言は「機密性n情報」と「公開範囲：〇〇のみ」とする(利用者が確認)。組織の規程が別の文言(取扱制限など)を定める場合はそれに従う。
- 枠は現在地の表示の上に置く。上余白を 48px から 80px に広げ、本文の高さは 32px 減る(確度: 中)。
