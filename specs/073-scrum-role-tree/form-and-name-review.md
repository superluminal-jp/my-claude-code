# 形と名前の判定（REQ-FORM）

`harness/skills/` と `harness/agents/` の22件すべてに、形の基準と改名の基準を当てた結果です。判定の日付は 2026-11-15 です。基準そのものは [requirements-graph.json](requirements-graph.json) の REQ-FORM にあり、表の規則は `evidence/check_form_review.py` が確かめます。

- **形の基準**: 要素の主な用途で、次の (a) と (b) が常に成り立つものをエージェントにし、それ以外をスキルにする。
  - (a) 作者から独立した読み手が要る、出力が長く結果だけが要る、または独立に並べて進められる。
  - (b) 人との対話も、完了の判定も要らない。
- **改名の基準**: 名前が要素の実際の目的と違うことを述べている場合か、一覧の読み手が役割を取り違える場合だけ改名する。

**結論**: 形も名前も、基準が変更を選んだ要素はありません。形が変わるのは、(a) と (b) が両方とも常に成り立つスキルか、どちらかが成り立たないエージェントです。そのどちらもありませんでした。
